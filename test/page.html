Trang thử nghiệm Read Aloud

Cách mở đúng: chạy node test/serve.js rồi mở http://127.0.0.1:8765/. Reload extension tại chrome://extensions sau mỗi lần sửa code. Mỗi đoạn: hover nửa giây để hiện nút ▶ — highlight theo từng câu và từng từ khi đọc.

Xin chào! Đây là trang web dùng để kiểm tra extension đọc văn bản.

Extension sẽ highlight từng câu và tự động cuộn trang xuống khi đọc.

Bạn có thể dùng Web Speech API miễn phí hoặc cấu hình Azure Speech / Google Cloud TTS trong popup.

Hãy nhấn nút extension và chọn "Đọc trang" để bắt đầu nghe nội dung.

Chúc bạn có trải nghiệm đọc thoại tuyệt vời trên mọi trang web!
